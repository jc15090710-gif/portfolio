# XD参照版・更新内容
- 配色・フォント・基本構成は前の生成り・茶色のまま
- 書影をクリック可能にし、右下に「作品を見る ↗」などのラベルを常時表示（マウスを重ねると画像も反応）
- 書影と作品ページ／購入ページのボタンは同じURLに設定してください
- URLが未指定のため、現時点ではクリックすると「リンク先未設定」と表示します。**実際の外部ページへはまだ遷移しません**
- `index.html` の `data-unset-link` がある `href="#"` を正しいURLに書き換え、`data-unset-link="..."` 属性を削除すると外部リンクになります
- `latest` → `news`
- ピューリたん単行本の発行年 → 2019
- contactの文章は「ご連絡ください。」の後で改行
- 「メール送信」ボタンとSNS／依頼ボタンを濃い茶色の白抜きピル型に変更
- SNSには文字アイコンを追加。Instagram／YouTube／noteは仮のトップページURLなので、実際のアカウントURLに変更してください
- メール送信はメールアプリ起動方式です。メールアドレス `hello@example.com` を `index.html` と `script.js` の両方で差し替えてください
